## Cómo trabajo

- **Commits con intención**: mensajes en formato convencional (`feat:`, `fix:`, `test:`, `docs:`).
- **Ramas de trabajo** y commits atómicos, para dejar el historial de las decisiones.
- **Pruebas antes de decir que funciona**: JUnit para la lógica, Mockito para aislar dependencias.
- **Integración continua** en los proyectos donde aporta: MallaLab y la kata de TDD compilan y ejecutan sus pruebas en GitHub Actions con cada push.
